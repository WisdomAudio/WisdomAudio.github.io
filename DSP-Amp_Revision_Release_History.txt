Known Bugs (new gen hardware specific):
> Some systems come up too fast and the Router will assign a new IP address after reload, as the old one is still being held in use.
> Firmware Update from firmware prior to Rev-xx-xx-46_WebUI-16, or from any previous version to Rev xx-xx-72 or higher, loads but does not reboot correctly sometimes. Requires a Manual Power off from the rear panel to complete normally.
> In the Speakers-->Advanced Controls-->Crossover: Changing the Crossover Order or Type does not recalculate the available PEQ for the channel. It is possible to have PEQ in the speaker preset that is not active as the maximum DSP has been exceeded. This is a very advanced feature so be careful!
> When test tone is on and the amp is placed in standby, if the network power save is OFF then on power on the webpage does not update to reflect the reset test tones and enabled speakers. Page must be manually reloaded.

Coming Soon:
> Added 1st order hi low filter into Channel User EQ for fine adjustment of rolloff and phase during calibration
> Add ping/pong from webpage (client) to close if amplifier (server) is powered off or not responding within a short time, instead of waiting for Router to update open hosts or become stale.

> User stored snapshot ("PRESETS") to store and recall Channels and Speakers configuration in real time.
> DANTE network IP and Hardware config information displayed on NETWORK tab, with the ability to reset to DHCP.
> Firmware Update shows files being unpacked on amplifier (server) after upload from computer (client).

Release 2024-9-16

SA8DSP_Rev-02-50_WebUI-20

Changes/Enhancements:
> Adds updates to the speaker profiles for: HLS; S57i; SRS; P2i; P4i; P6i; L8i. Insight in-wall models now feature FIR filter phase correction. Updates to ICS3/Sub1 profiles for use with and without each other as a Sub/Sat.
> Increased User EQ from 10 bands to 12 bands and reduced IIR PEQ on Driver EQ for magnitude correction, since all speaker profiles use FIR filter for Phase and Magnitude (mixed phase filters). 
	*Note: this only applies to newly created channels. Existing systems will need to delete and recreate the channel to see these 2 new filters.
> New ESS ADC input filter settings for lower noise and distortion on analog inputs, with improved Impulse response.
> New internal Speaker Polarity/Alignment pop Test using pulse tone for more consistent output and easier reading of results
> Increased channel delay maximum from 30ms to 35ms across all channels
> All subwoofer Speaker Profiles now have access to up to 8th order Low Pass to assist in creating a proper bass management slope, for preamps that only have 2nd order asymetrical (THX Legacy) slopes.
> Adjusted internal test Pink Noise to be -20dbfs through the signal chain to align with Dolby and CEDIA spec for output SPL test levels, turn on default is -40dbfs
> Significantly improved the speed of webpage load from the amplifier to the web browser.
> Added 1st order all pass / hi low filter into DSP hardware for phase alignment during speaker setup (for use with Factory Calibration Services). This is not enabled in the WebUI at this time.
> Added Output Limiter into driver signal chain to safely limit the input signal without overdriving the amp channels input (safety limiter). This cannot be seen by the end-user.
> Allows for 2 concurrent WebUI sessions at a time. NOTE: If 2 users access the same page at the same time, the last person to make a change will overwrite the older session.
> Changed power supply monitor so that audio will continue to play until the caps are discharged. If there is a power supply fault (Temperature or Hardware Failure), the system will log the event, blink the front panel, and attempt to allow the power supply to recover. Audio will no longer automatically mute.
> Changed output clipping monitor to ignore any clip event that is less than 1000ms in length.

Bug Fixes:
> Fixed an error in the DHCP code, which may have caused an improper DHCP address
> Added log entry for updating the system time from the internet (pool.ntp.org)
> Fixed Point3-GT In-wall profile (Gen2 with FIR) to properly send all FIR filters when selected. Previously had only sent IIR filters. On-Wall profile was not impacted.
> Eliminates the Dante Audio Input turn on POP, with an automatic and dynamic monitoring of the input signal to MUTE whenever signal Lock is lost. This replaces a turn on timer which could would update in real time if signal was lost.
> Corrected Dante input polarity to match analog input polarity across all signal paths.
> Added hardware controlled DSP Mute (GPIO) for future use with fast turn on standby mode.
> Increased internal SPI Bus speed to maximum for Network Interface
> Enabled the WebServer ping/pong mechanism to reset the network connection to dropped clients (Web UI Page on Web browser) after 30 seconds of no response from client.
